# RunTogether — version 0.1

Petit site web d'entraînement sur piste pour Tom, Tika et Taki.

## Lancer le site
1. Décompressez `runtogether.zip`.
2. Ouvrez `index.html` dans un navigateur récent (Chrome, Firefox, Safari ou Edge).
3. Ajoutez une série ou utilisez « Charger une séance exemple ».
4. Appuyez sur « Démarrer » au départ, puis touchez le bouton de chaque coureur à son arrivée.

## Fonctions présentes
- Chronomètre commun avec enregistrement individuel de l'arrivée de Tom, Tika et Taki.
- Création de séries (distance, répétitions, récupération).
- Historique des chronos dans le stockage local du navigateur.
- Modification des allures de départ et projection mathématique sur 10 km.
- Export CSV des résultats.

## Limites connues de cette première version
- Les données restent dans le navigateur et sur cet appareil : elles ne sont pas synchronisées entre téléphones.
- Les temps sont pris en touchant le bouton d'arrivée ; ce n'est pas un système de chronométrage électronique.
- La récupération est affichée mais pas encore chronométrée automatiquement.
- La progression et les plans d'entraînement personnalisés seront développés dans les prochaines versions.
- Les données sont enregistrées localement ; évitez d'effacer les données du navigateur avant export.

## Idées pour la suite
1. Calendrier des séances et bibliothèque de séances réutilisables.
2. Graphiques de progression par distance et par coureur.
3. Calcul des allures cibles et temps de passage.
4. Chronomètre de récupération automatique.
5. Synchronisation entre les appareils via une base de données.
6. Génération progressive d'un plan pour courir 10 km plus vite.

Les allures initiales sont des informations fournies pour démarrer le projet, pas une évaluation sportive.
